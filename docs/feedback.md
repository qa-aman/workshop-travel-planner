# Feedback

Every correction Aman gives during this project is recorded here the same turn it happens, so the same mistake is not made twice. Newest at the top. This applies to every kind of work on this project: planning, development, review, docs, demo prep.

Each entry has: what was corrected, the durable lesson behind it (the class of mistake, not the instance), and the check that prevents it next time. If the lesson is general enough to apply beyond this project, it is also logged in the global ledger at `~/.claude/rules/feedback-driven-lessons.md`.

Standing rule: whenever a correction lands, add it here before continuing the task. If a subagent is the one corrected, the controller adds it.
