How the agents in this repo talk to each other

Every box below is one of the files in .claude/agents/. Click through the steps to see the order, which agents run at the same time, and the file each one reads or writes to hand off its work. There is no direct agent-to-agent call anywhere, every handoff goes through a file on disk plus a short text summary back to the orchestrator.

The one rule that explains everything below: agents never call each other. The orchestrator (the main Claude Code session) dispatches each subagent with the Agent tool, the subagent reads only the file paths it was given, writes its own output file, and returns 2-3 lines of plain text. The orchestrator is the only thing that ever reads more than one agent's output.
